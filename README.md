### Sobre mí

Soy **Rony Valdelamar**, Ingeniero de Sistemas y desarrollador web en Cartagena de Indias, Colombia.
Construyo soluciones a la medida —plataformas web, paneles administrativos y herramientas internas—
con tecnologías modernas, y acompaño a organizaciones en la parte técnica: dominios, hosting,
correo corporativo y soporte TI.
